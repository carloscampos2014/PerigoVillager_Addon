# 📦 Perigo Villager Addon

"Quer comprar um relógio? Tenho um que marca as horas antes delas acontecerem."

Addon para Minecraft Bedrock que traz o **Perigo** (Todo Mundo Odeia o Chris) para o seu mundo. Villagers invocados via blocos com trocas de procedência duvidosa (itens de elite por preço de lixo).

## 🛠️ Como Invocar os Vendedores
Combine uma **Abóbora Entalhada** sobre o bloco correspondente na Bancada de Trabalho:

| Bloco Base | Vendedor (Profissão) | Resultado |
| :--- | :--- | :--- |
| **Feno** | Agricultor | Ovo de Invocação |
| **Pedra** | Pedreiro | Ovo de Invocação |
| **Bloco de Ferro** | Ferreiro | Ovo de Invocação |
| **Bloco de Ouro** | Armeiro | Ovo de Invocação |

## 💰 Sistema de Trocas (Caiu do Caminhão)
As trocas são extremamente baratas porque os itens... bem, você sabe:
* **Terra/Graveto** ➔ Picaretas e Armas de Netherite (Encantamento Nível 50).
* **Trigo** ➔ Packs de Esmeralda ou Totens da Eternidade.
* **Maçã** ➔ Maçãs Douradas Encantadas.

## 📂 Estrutura do Projeto
* `BP/`: Behavior Pack - Comportamentos, trocas e receitas.
* `RP/`: Resource Pack - Texturas e modelos.

## 🚀 Instalação
1. Baixe ou clone este repositório.
2. Copie as pastas `BP` e `RP` para a pasta de development packs do seu Minecraft.
3. Ative os pacotes nos experimentos do seu mundo.
